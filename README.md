# M5-OBD-CO2-Monitor

M5Stack CoreS3を使用した車載マルチモニターシステムです。OBD2経由で車両データを取得し、CO2センサーで車内環境を監視します。

## 📋 機能概要

### データ収集
- **車両データ (OBD2/CAN)**
  - エンジン水温
  - スロットル（アクセル）開度
  - 制御モジュール電圧（バッテリー電圧）
  
- **環境センサー (SCD40)**
  - CO2濃度 (ppm)
  - 車内温度
  - 湿度

### 表示機能
- **ヘッダー**: バッテリー電圧とCO2濃度をリアルタイム表示
- **スロットルゲージ**: アクセル開度を円形ゲージで表示
- **水温表示**: 温度に応じた色変化（青→黄→オレンジ→赤）
- **車内環境**: 温度と湿度を表示
- **履歴グラフ**: スロットル開度の過去160秒間の推移を折れ線グラフで表示

### 通知機能
- **LED通知** (WS2812 LEDストリップ)
  - CO2 1250ppm以上: 黄色で呼吸エフェクト
  - CO2 1500ppm以上: 赤色で呼吸エフェクト
  
- **音声通知**
  - 暖機完了 (75°C到達): 「ポン」音
  - 冷却検出 (60°C以下に低下): 「ポンポン」音
  - CO2警告 (1500ppm超過): 「ビー」音

## 🔧 ハードウェア構成

| 部品 | 接続先 | 説明 |
|------|--------|------|
| M5Stack CoreS3 | - | メインデバイス (ESP32-S3) |
| SCD40 CO2センサー | Port A (I2C) | CO2/温度/湿度センサー |
| CAN Unit | Port C (TX=17, RX=18) | OBD2通信用 |
| WS2812 LEDストリップ | Base Pin 5 | 10個のLED |
| 内蔵スピーカー | - | 通知音用 |

### 接続図
```
M5Stack CoreS3
├── Port A (I2C) ── SCD40 CO2 Sensor
├── Port C (UART) ── CAN Unit ── OBD2 (車両)
├── Pin 5 ── WS2812 LED Strip (10 LEDs)
└── 内蔵スピーカー
```

## ⚙️ 設定とカスタマイズ

### スロットル値の変換
OBD2から取得した生のスロットル値は、以下のようにマッピングされます：
- 15%以下 → 0%
- 75%以上 → 100%
- 15%〜75% → 0%〜100%に線形補間

### CO2センサーの温度オフセット
`Co2Sensor::setTemperatureOffset()` メソッドで温度補正が可能です。

### デバッグモード
`CanManager::setDebugEnabled(true)` でCAN通信の詳細ログを有効化できます（2秒間隔）。

## 🔍 技術仕様

### パフォーマンス
- **画面更新**: 約30fps (33ms間隔)
- **グラフ更新**: 500ms間隔
- **CAN通信**: 200ms間隔でポーリング
- **CO2センサー**: 5秒間隔で読み取り
- **LED更新**: 3秒サイクルの呼吸エフェクト

### アーキテクチャ
- **ノンブロッキング設計**: 全コンポーネントは`update()`メソッドで非同期更新
- **スプライトレンダリング**: チラツキ防止のためスプライト使用
- **非同期音声再生**: トーンシーケンスキューによる非同期再生
